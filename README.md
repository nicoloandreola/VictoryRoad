# VictoryRoad
VictoryRoad è un RPG desktop ispirato a Inazuma Eleven, in cui il giocatore è chiamato a scegliere un protagonista e affrontare una serie 
di avversari in match 1 contro 1, avanzando tra i livelli, apprendendo nuove tecniche speciali e migliorando le proprie statistiche.
Riuscirai a sconfiggere gli alieni e a salvare il mondo? Scendi subito in campo!

---

## Come eseguire il progetto

### Prerequisiti

- Java 25 (LTS)
- Gradle

### Avvio rapido
Tuttavia, grazie all'alta portabilità di Gradle, fornita tramite il **Gradle Wrapper**, è possibile avviare il progetto semplicemente con i seguenti
comandi, anche se non si hanno tutti gli strumenti necessari installati sulla propria macchina (penseranno a tutto gli script gradlew e gradlew.bat).

```bash
git clone https://github.com/nicoloandreola/VictoryRoad.git
cd VictoryRoad
./gradlew build
./gradlew run
```

## Uso di strumenti di AI
Durante la realizzazione del progetto è stato utilizzato ChatGPT come strumento di supporto e revisione: le scelte progettuali, 
l'implementazione finale e la verifica del comportamento dell'applicazione sono state effettuate personalmente.
Solamente in alcuni casi l'AI ha fornito esempi o proposte iniziali di implementazione; ma comunque tutte le soluzioni proposte 
sono state successivamente analizzate, comprese e adattate al progetto prima di essere integrate nel codice finale.

In particolare, è stato utilizzato per: <br>
approfondire aspetti teorici e pratici relativi soprattutto a JavaFX <br>
confrontare possibili alternative di progettazione e organizzazione del codice <br>
analizzare errori e problemi incontrati durante lo sviluppo <br>
generare o modificare alcune risorse grafiche utilizzate nell'interfaccia <br>

Per una descrizione più dettagliata dell'utilizzo degli strumenti di AI è disponibile la Wiki del progetto.
